# P7 设计稿：记忆效用反馈闭环 + 主动判别式召回

> 状态：草案（P7 候选，未排期）。关联决策：adr/ADR-003；理论依据：architecture/D4 §9。
> 定位：漏斗式召回管线的两块落地件——⑤ 结果回写的定量化（效用反馈闭环）与 ③ 判别探测的从零实现（主动判别式召回），互为姊妹件。
> 日期：2026-08-20

---

## 0. 结论先行

1. **效用反馈闭环** = 食溯问卷逻辑的记忆版：每次召回留痕、反馈回传、逐条记忆维护效用分（EMA），效用分参与召回排序。非参数化，V2 插件通道可承载，不动客户端。
2. **主动判别式召回** = 漏斗 ③ 的从零实现：当粗筛结果存在多个近似候选时，系统主动给出/追问**最小判别特征**（章鱼还是鱿鱼——尖头还是圆头），再锁定召回。当前架构全空白。
3. 两者共用同一套**召回事件留痕**数据结构（ADR-003 数据工厂条款的执行层）。
4. 公共基准（SWE-context-bench / LoCoMo-Refined / LongMemEval）接入评测门做外部参照，只内测不打榜。

## 1. 组件 A：效用反馈闭环

### 1.1 反馈事件数据结构（留痕层，两组件共用）

每次召回事件追加一条记录（append-only，进记忆库侧表）：

| 字段 | 说明 |
|---|---|
| event_id / timestamp | 主键与时间 |
| memory_ids | 本次召回的记忆条目 |
| task_type | 漏斗①判型结果（任务/问题类型） |
| recall_stage | 召回发生在漏斗哪一级（判型/枚举/探测/精排） |
| cue_features | 触发本次召回的线索特征（类型/情境/关键词） |
| explicit_feedback | 显式反馈：有用 / 没用 / 未评价（稀但准） |
| implicit_outcome | 隐式结果：是否进入最终产出 / 任务是否解决 / 用户是否返工（稠但噪） |
| end_source | 来源端（dsh / codex / zcode / kimi…，ADR-001 单一数据根） |

### 1.2 效用更新规则

- 每条记忆维护 `utility`（EMA）：`utility ← (1-α)·utility + α·reward`，reward 由显式反馈（主）与隐式结果（辅）合成。
- 显式/隐式权重配比：沿用食溯问卷的配比经验（显式稀但准、隐式稠但噪），初始值在设计评审时定，后期用评测门数据自校准。
- 时效衰减：长期未取用的记忆效用自然衰减（对应适应性遗忘的可及性开关，D4 §9.2 第三线）；被显式标记「长期留存」的记忆豁免衰减——对应「哪些该记」的显式答案。
- **效用参与排序**：召回综合分 = 结构匹配（漏斗前三级） × 效用权重；效用只调序、不决定是否进入漏斗（防止高效用记忆垄断入口——反「自作聪明」纪律，对照 MemoraX 85.5% 触发一致率基线）。

### 1.3 与评测门的接口

- 留痕日志即评测原料：每层 R 层 GO/NO-GO 复跑时，效用分布变化作为回归指标之一。
- 留痕日志即未来策略学习的训练集（ADR-003 数据工厂条款）：不训练，但必须可训练。

## 2. 组件 B：主动判别式召回（漏斗 ③）

### 2.1 触发条件

粗筛（漏斗①②）返回多个近似候选且无法凭现有线索区分时，进入判别探测，而非直接把候选全塞进上下文（「刚刚好」判据禁止兜底式多召回）。

### 2.2 判别特征 schema（编码侧配套）

记忆条目在提取阶段除内容外，须登记（ADR-003 决策 1 的编码侧落地）：

| 字段 | 说明 |
|---|---|
| type | 类型标记（问题/经验/决策/偏好…，类型表进 Catalog） |
| structure_features | 结构特征（该记忆在解空间中的位置：适用于哪类问题、属于哪种解法路径） |
| discriminators | 判别特征列表（与最易混淆项的最小差异——「尖头 vs 圆头」） |

### 2.3 探测策略

- 从候选集的判别特征交集中选**信息增益最大**的一条，向用户/上下文发起单点确认（一轮，不多问）；确认后锁定候选并精排。
- 探测失败（用户无响应/无法区分）→ 降级为带不确定性标注的多候选呈现，并在留痕中标记「判别失败」供 Daydream 回写补全特征。
- 探测本身也是留痕事件（recall_stage = 探测），其成功率进评测门。

## 4. 通道与治理

- 全部改动在 memory 插件内，走 V2 插件通道（D1 §9.3 前提满足后）；不涉及客户端。
- 变更级别（D2 §3.6）：效用排序调参、判别特征表扩充 = Class B（评测门全绿即放行）；反馈数据结构/记忆 schema 变更（含迁移）= Class A（Cyrus 拍板）。
- 文档门：本设计稿评审通过后，其验收标准进 NEXT.md 交接段。
