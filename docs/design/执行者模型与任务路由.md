## 2. 路由规则（草案）

1. **"谁来做"是审批项**：每条任务卡除四件套（目标/验收标准/证据要求/自报级别）外，必须带"拟定执行者 + 成本档"；批准一张卡 = 同时批准内容与路由。
2. **成本下沉原则**：能用 Flash 的活不升级到 Pro/K3；批量提取、批量改写、脚本可完成的任务默认最低可用档。（与食溯"能用脚本用脚本，能用 LLM 用 LLM"同构。）
3. **路由违规拦截**：高成本执行者提议亲自执行批量任务 = 路由违规，控制台应标红；审查（Codex）不返工实现，实现（Flash/Pro）不自审。
4. **跨端接力入队**：文档在多端间的评审/复核经控制台队列流转，不再由 Cyrus 人肉乒乓（实证见 Codex 挖掘 §3 模式 1）。
5. **额度即路由上下文**：各端额度状态进入路由决策（实证：08-14 额度耗尽触发开发移交）。
