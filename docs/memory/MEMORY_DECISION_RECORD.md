## 2. 15 项最终选择

| # | 决策 | 结论 |
|---|---|---|
| 1 | 备份频率 | A+：每日验证快照 + 危险变更前 RPO=0；RPO≤24h、RTO≤2h、季度演练 |
| 2 | 异物理备份 | 另一物理设备，加密/版本化/不可变快照；禁镜像与删除同步；云端暂不启用 |
| 3 | 恢复密钥 | 24 词或等价高熵恢复码（标准编码）；两份纸质离线；密码管理器只作附加；分级轮换 |
| 4 | 数据边界 | 商业机密按项目 opt-in；健康/家庭仅显式；原始医疗/遗传只存引用；身份证/账号/凭据永不存 |
| 5 | System Policy | 二次评审修订 8 条（手册 §3.1）；覆盖所有可写 agent/子代理；minimal/complete 不得用于可写项目 |
| 6 | 项目身份 | 方案 D：复用 Project Control project_id + Session 绑定；不建第二套注册表 |
| 7 | Git | 同意建本地 Git 无 remote；init/忽略清单/首个 commit 仍需单独批准；不承担项目身份 |
| 8 | AGENTS 投影 | 只投影 Dev DSH_HOME；Stable 走安装/升级流程；每次投影单独申请 |
| 9 | 经验.md | 单向：过渡期 md canonical→DB 索引；成熟后 DB canonical→生成只读 md；禁止双向同步 |
| 10 | 跨会话 | 官方 Session 管原文；自建库只存提炼 claim；P0 核验官方保留/删除/导出边界 |
| 11 | Gate | 四波：路径/PID → secret/PII+外部授权成对 → 记忆 scope/加密/备份 → 构建发布；每波单独批准 |
| 12 | Portfolio | 模型支持、共享 allowlist 初始为空；只分组统计不跨项目召回 |
| 13 | 自动候选 | 初期关闭；P3 后仅按项目试点技术经验，带 pause/周摘要/TTL/敏感拦截 |
| 14 | 规模验收 | 两级：发布基线 10 active/40 archived/5 万 claims/25 万 relations/5 并发；扩展压力 30/100/20 万/100 万/10 并发；leak 恒 0 |
| 15 | 加密时机 | 第一次写入真实个人/商业记忆前启用 live DB 加密；此前仅合成 fixture |
