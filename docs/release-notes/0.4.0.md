# DeepSeek Harness Personal v0.4.0（稳定版）

发布日期：2026-08-20

## 概述

本版将稳定版客户端升级到 Harness `0.1.0-rc.8`，并完成工作台体验收口、浏览器页签架构重写、会话导航轨等一批功能与稳定性改进。

## 主要更新

### Workbench 工作台
- 根外 `.md` 文件可在工作台内打开（显式 workspaceRoot 全链路 + ad-hoc 根兜底）。
- 预览中的 http 外链转系统默认浏览器；裸域名自动补 `https://`。
- 文件树/搜索结果/路径浮层统一使用文件类型图标（`FileIcon`）。
- 文件树 dock 支持拖动分隔条（220–560px，宽度记忆）。
- 编辑器工具栏 12px 分组图标化；段落下拉卡片化并回显当前类型；悬浮菜单对齐修复。
- 斜杠命令新增图片/媒体、文件/附件、数据库/表格视图，并支持本地文件/图片拖拽与选择。

### 浏览器页签
- 从渲染进程内嵌 `<webview>` 重写为主进程 `WebContentsView` 叠加。
- 解决白屏、嵌入限制、宿主崩溃三类问题。
- 冒烟已验证 Google / 百度 / Kimi 可正常渲染。

### 会话导航轨
- 轨迹岛废弃重写为会话导航轨（`SessionMinimap`）。
- 贴会话右缘 14px 垂直细轨，刻度以中轴为中心向上下发散。
- 用户轮/助手轮长短区分、running 脉冲、error 红、当前位置高亮。
- 悬停弹缩略卡，点击跳转到对应聊天锚点。

### 基础升级
- Harness 运行时升级到 `0.1.0-rc.8`（commit `141eb6f`）。
- 18 个个人插件全部针对 rc.8 重建并通过门禁。
- 本地补丁：`tsdown.client.ts` 非 workspace 插件构建 fallback；`dsh web --no-open` 适配。
