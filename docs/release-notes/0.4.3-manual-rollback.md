# v0.4.3 过桥客户端 · 第一跳人工回退说明

> 适用：0.4.2 → 0.4.3（过桥版）的第一跳。过桥版成功启动并登记 `knownGoodDesktop` 后，
> 后续升级进入应用内自动回滚，不再依赖本文。

## 为什么需要人工回退

0.4.2 的 `update-center.json` 没有 `knownGoodDesktop` / `previousDesktop` / `installPending` /
`rollbackPending`。因此升级到 0.4.3 时无法自动把 0.4.2 保存为可回滚安装包；本版只能保证
「过桥版成功后，后续版本可自动回滚」。

## 何时回退

- v0.4.3 安装后启动失败、长时间停留在加载壳、或无法通过 readiness/doctor；
- v0.4.3 尚未完成首次成功启动（即尚未写入 `knownGoodDesktop`）。

若 v0.4.3 已成功启动过一次，请优先使用应用内「设置 → 更新中心 → 回滚客户端」。

## 操作步骤

1. 退出 v0.4.3（能关则关；不能关则从任务管理器结束 `DeepSeek Harness Personal.exe`）。
2. 确认手上存在 `DeepSeek-Harness-Personal-0.4.2-setup-x64.exe`，并核对 SHA-256。
3. 双击 0.4.2 安装包，选择与 v0.4.3 相同的安装目录，覆盖安装。
4. 启动 0.4.2，确认：
   - 主窗口出现；
   - Harness 页面真实加载（不是停留在引导壳）；
   - 可正常退出，端口关闭。
5. 保留 0.4.2 安装包，用于下一次升级失败时再次人工回退。

## 禁止事项

- 不要删除或改写 `%APPDATA%\DeepSeek Harness Personal\update-center.json` 来“假装回滚”。
- 不要删除 `%APPDATA%\DeepSeek Harness Personal`、`F:\documents\Cyrus Deepseek Harness Data` 等数据目录。
- 不要修改 `D:\Deepseek Harness` 上游。
