# DeepSeek Harness Personal v0.2.0（稳定版）

v0.2.0 带来两个主题：**长期记忆系统正式上线**，以及**工作台审阅体验重构**。

## 长期记忆系统（首发）

- 跨会话记忆：说「记住…」写入，问「之前/上次…」自动召回；写入前人工确认，可更正、归档、查询、导出
- 归类硬规则：项目专属内容写项目分片（项目需先在项目控制台登记，未登记一律拒绝写入）；跨项目通用经验写全局分片，绝不混串
- 渐进披露：会话开始时注入紧凑摘要（默认按需开启），细节按需召回并标注「历史记忆、可能过时」
- 静态加密：SQLCipher 全库加密 + 主密钥 DPAPI 账户级保护 + 恢复口令（12 词）灾备；明文旧库自动原地升级
- 每次备份为一致性加密快照；JSONL 导入导出；记忆库按版本隔离存放

## 工作台审阅体验

- 文件树停靠在工作台右侧（可折叠）；树顶部搜索框快速找文件；右键复制路径 / 在资源管理器中打开
- 文件树与预览跟随控制台选中的项目；项目文件只读预览，安全有界（路径逃逸防护、忽略目录、大小上限）
- 顶栏两行式：页签行 + 路径行（打开文件夹 / 路径段目录悬浮窗 / Details / 文件树开关 / 布局菜单）
- Markdown 双模式：预览（笔记式排版：标题层级、引用、表格、任务清单、代码块）与代码（原文视图）切换
- 全屏模式（工作台横跨三区）、5K 宽屏可用宽度、字号随主题基础字号整体缩放

## 修复

- 开发版启动自动弹目录选择框（冒烟探针泄漏）
- 候选确认「只关联」按钮被重复角色卡死（一键自动处理 + 冲突高亮）
- 改下拉框导致工作台消失的崩溃；大文件预览响应上限

## 安装与升级

- 已装 v0.1.1：应用内「设置 → 更新中心 → 检查更新」应提示 v0.2.0，按提示下载安装；或人工下载 setup exe 覆盖安装
- 新装：运行 setup exe 安装；便携版双击运行，升级 = 替换 exe
- 两个包体可并存，数据目录相互独立

## 已知说明

- 首次启动会在记忆库目录生成一次性恢复口令文件，请转存到你的密钥库后删除该文件
- 当前构建未做代码签名，Windows 首次运行可能提示「未知发布者」，需手动允许
- 更新仓库为公开仓库；更新中心只做 HTTPS 下载与 SHA-256 校验
- 本版为早期版本，部分能力仍在迭代中
