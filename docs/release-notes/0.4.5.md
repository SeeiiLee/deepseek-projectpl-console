# DeepSeek Harness Personal v0.4.5（稳定版·发布候选）

## 概述

v0.4.5 在 v0.4.4 基础上完成更新中心“当前有效插件版本”识别与 pending generation 安全收口。

- 更新中心现在读取并验证 `plugins-external/current.json` 指向的 generation，external 插件显示为“独立更新源”，不再误显示“随客户端更新”。
- 更新检查以“当前实际生效版本”与远端版本比较；同版本不重复提示。
- pending 状态显示“已准备，重启后激活”，且 pending 存在时禁止准备新的插件 generation。
- current/pending 统一目录包含、版本安全、junction/symlink 越界校验。
- 全量测试：**751/751**，fail 0，skipped 0。
- stable packed 激活/重启/回滚 E2E 通过。
- 本文件为发布候选资料，等待 Cyrus 授权发布。
