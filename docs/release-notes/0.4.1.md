# DeepSeek Harness Personal v0.4.1（稳定版·启动修复补丁）

发布日期：2026-08-21

## 概述

本版为 v0.4.0 的启动修复补丁，无功能变更。修复部分环境下客户端启动失败的两类问题。

## 修复内容

### 1. 兼容旧版 Harness 运行时（启动失败主因）

- 问题：v0.4.0 启动时固定向 Harness 传递仅新版本支持的 `--no-open` 参数，旧版运行时不识别该参数会直接退出，客户端报「Harness did not become ready / unknown option '--no-open'」。
- 修复：启动前自动检测运行时版本，仅在支持时传递该参数；任何版本组合均可正常启动。

### 2. 系统 Node 查找过滤脚本包装器（spawn EINVAL）

- 问题：在 PATH 中 `node.cmd` 等脚本包装器排在 `node.exe` 之前的机器上，客户端启动 Helper 进程时报「spawn EINVAL」。
- 修复：查找系统 Node 时跳过 `.cmd` / `.bat` / `.ps1` 包装器，只使用真正的可执行文件。

### 3. 打包完整性修复

- 将 Koffi 原生运行库（`@koromix/koffi-win32-x64`）纳入显式依赖，修复打包产物在部分机器上因缺少原生模块而无法启动的问题。
