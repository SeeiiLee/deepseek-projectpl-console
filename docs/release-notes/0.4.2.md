# DeepSeek Harness Personal v0.4.2（稳定版·更新中心修复补丁）

发布日期：2026-08-21

## 概述

本版为更新中心修复补丁，无功能变更。修复在未安装全局 Node/pnpm 工具链的机器上，通过更新中心升级 Harness 运行时失败的两类问题。

## 修复内容

### 1. 更新中心自带 pnpm（不再依赖系统全局工具链）

- 问题：更新中心执行运行时升级时直接调用系统 `pnpm.cmd`，在未安装全局 pnpm 的机器上报「'pnpm.cmd' 不是内部或外部命令」，升级无法进行。
- 修复：应用随包内置 pnpm（`vendor/pnpm`），更新流程优先使用内置副本、通过已验证的真实 Node 可执行文件运行；仅当内置副本缺失时才退回系统 PATH。

### 2. 隔离环境 npm 配置冲突（double-loading config）

- 问题：更新流程为隔离环境把 npm 的用户级与全局配置文件指向同一文件，新版 npm 拒绝重复加载并报「double-loading config … as "global", previously loaded as "user"」，导致上游运行时构建失败。
- 修复：全局配置改用独立文件，两类配置不再冲突。
