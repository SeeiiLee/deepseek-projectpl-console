# DeepSeek Harness Personal v0.2.1（稳定版）

在 v0.2.0 基础上发布 v0.2.1，修复一处初始化时序问题。

## 本版修复

- 记忆库加密初始化改为**每次启动自动执行**：首次启动即生成主密钥与一次性恢复口令文件，并把已有明文记忆数据原地升级为密文（v0.2.0 中该初始化被延迟到首次使用记忆时，恢复口令文件出现时机不可预期）。

## 功能集（同 v0.2.0）

- 长期记忆系统：跨会话记忆、写入前确认、归类硬规则、渐进披露、SQLCipher 全库加密 + DPAPI 主密钥 + 12 词恢复口令、加密快照备份、JSONL 导入导出
- 工作台：右侧文件树停靠与搜索、项目绑定、路径栏与目录悬浮窗、Markdown 预览/代码双模式、全屏、宽屏适配
- 项目控制台候选确认一键处理重复角色等修复

## 安装与升级

- 已装 v0.2.0：应用内「设置 → 更新中心 → 检查更新」应提示 v0.2.1，按提示下载安装
- 升级后首次启动：记忆库目录生成一次性恢复口令文件，请转存到你的密钥库后删除该文件
