# DeepSeek Harness Personal v0.3.0（稳定版）

在 v0.2.1 基础上统一发布：记忆系统 P4（本地嵌入 + hybrid 召回）、P6 稳定化硬门、Codex 历史导入工具，以及一批启动/窗口/工作台修复。

## 本版新增

- **本地嵌入与 hybrid 召回（P4）**：bge-m3 ONNX 本地 CPU 嵌入（无外发），FTS + 向量融合召回，默认开启；`DSH_MEMORY_HYBRID=0` 可一键关断。模型目录按环境自动解析（环境变量 > 数据根 models\bge-m3-onnx）。
- **记忆稳定化硬门（P6-1）**：memory.reset_project（预览 + 双重确认 + 审计回执）、加密快照恢复与整机迁移演练通过、shadow import 对账切换回滚、多项目并发隔离。
- **Codex 历史导入工具（P6-0C）**：memory_import_codex——从 Codex 会话历史 staging 包提取候选记忆，默认 dry-run 零成本，正式运行有预算硬上限与空闲时段闸门，候选带 codex:// 证据、人工确认后才生效。
- **原生侧栏工作区 → 工作台文件树联动**：点击侧栏项目/会话，右侧文件树自动切到对应项目根。
- **启动加速 + 白闪收口**：启动即有深色引导窗反馈；白闪从「白底 HARNESS 转圈」收口为深色加载卡；启动器增量构建（6.3s → 0.7s）。
- **审阅页签持久化**：打开的文件/预览页签跨会话、跨控制台存活；固定 Web 端口（稳定版 50682），会话/布局偏好不再每次启动清零。
- **窗口边界记忆**：窗口尺寸/位置/最大化状态跨启动保持（钳制到可见显示器）。
- **项目控制台记忆**：重启恢复上次打开的项目控制台。

## 本版修复

- 白闪根因修正（隐藏窗口残留旧帧 → 深色兜底 + 显示前强制新帧）
- 审阅页签启动失忆（查看器注册时序）
- 无 scope 页签打开落进不可见全局 scope，工作台只剩空占位
- 记忆插件打包漏 0004 迁移文件（files 改 migrations/*.sql 通配）
- boot 日志在 ESM 下从未落盘（appendFileSync + import.meta.url）
- 更新中心在 GitHub 列表接口索引延迟（列表为空）时误报「没有可用更新」→ 回退 /releases/latest（2026-08-17 实测该延迟曾使列表连续 30+ 分钟为空）

## 安装与升级

- 已装 v0.2.1：应用内「设置 → 更新中心 → 检查更新」应提示 v0.3.0，按提示下载安装
- 首次启用 hybrid 召回：请确认数据根 models\bge-m3-onnx 模型目录就位（随发布说明提供校验值），否则嵌入自动关闭，纯 FTS 召回不受影响
