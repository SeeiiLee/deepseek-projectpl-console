# DeepSeek Harness Personal v0.4.3（稳定版·A 线过桥客户端）

发布日期：2026-08-24（发布候选封版）

## 概述

本版是按 Cyrus 已拍板的「过桥版 + 第一跳人工回退」方案发布的 **A 线过桥客户端**。
当前稳定版 0.4.2 没有 `knownGoodDesktop` / `previousDesktop` / `installPending` / `rollbackPending`
生命周期状态，因此从 0.4.2 升级到本版属于第一跳：**本版不宣称自动回滚到 0.4.2**，
若本版首启失败，请按本文「第一跳人工回退」说明手工重装 0.4.2 安装包。

本版成功启动并完成 `knownGoodDesktop` 登记后，后续升级/回滚才进入应用内自动回滚生命周期。

## 第一跳人工回退说明

**回退条件**：仅当本版 v0.4.3 安装后无法正常启动，或启动后未完成 `knownGoodDesktop` 登记时，
使用人工回退。若已登记成功，优先使用应用内「设置 → 更新中心 → 回滚客户端」自动回退到上一已知良好版。

**人工回退步骤**：

1. 关闭 v0.4.3（若窗口可关闭）。
2. 保留/取得 v0.4.2 安装包：
   - 已安装过 0.4.2 的机器，使用升级前保留的 `DeepSeek-Harness-Personal-0.4.2-setup-x64.exe`；
   - 未保留时，从已授权的发布渠道重新下载 0.4.2 安装包，并核对 SHA-256。
3. 运行 0.4.2 安装包，按向导覆盖安装（同一安装目录）。
4. 启动 0.4.2，确认窗口正常显示、Harness 页面加载、可正常退出。
5. 回退完成后，不要删除 0.4.2 安装包；后续再次升级到过桥版时仍需保留人工回退能力。

**注意事项**：

- 第一跳人工回退不会自动清理 v0.4.3 的 `update-center.json` 生命周期字段；若安装向导提示版本回退，
  以实际安装目录和启动版本为准。
- 不要删除 `%APPDATA%\DeepSeek Harness Personal` 下的数据目录来做回退；回退只覆盖客户端程序文件，
  用户数据、项目库、会话数据保持不动。
