# DeepSeek Harness Personal v0.1.1（稳定版）

在 v0.1.0 功能集基础上发布 v0.1.1：**出厂预置更新仓库**，装好本版后应用内更新自动可用（设置 → 更新中心 → 检查更新）。

## 本版包含

- 四轨工作界面：侧边栏 / 项目控制台 / 会话 / 工作台，布局可调整并记忆
- 项目控制台：既有项目只读扫描与人工确认导入、标准模板快速新建、既有项目安全升级、文档索引与重命名重绑定
- 工作台：文件、代码、大纲、Diff、浏览器、终端、详情七个页签（部分页签当前为界面与路由，业务能力随版本逐步接入）
- 会话终端（PowerShell 集成）
- Skill 资料库、连接中心、插件整理、个人主题、桌面设置
- 用量与余额查看（本机查询，费用预估与官方余额区分）
- 轨迹岛、更新中心（本版起预置发布仓库）
- 图片理解与 AnySearch 联网搜索
- 稳定版数据独立存放；附数据迁移工具（旧数据无损迁至新数据目录）

## 安装与升级

- 已装 v0.1.0：应用内「设置 → 更新中心 → 检查更新」应提示 v0.1.1，按提示下载安装；或人工下载 setup exe 覆盖安装
- 新装：运行 setup exe 安装；便携版双击运行，升级 = 替换 exe
- 两个包体可并存，数据目录相互独立

## 已知说明

- 当前构建未做代码签名，Windows 首次运行可能提示「未知发布者」，需手动允许
- 更新仓库为公开仓库；更新中心只做 HTTPS 下载与 SHA-256 校验
- 本版为早期版本，部分能力仍在迭代中
