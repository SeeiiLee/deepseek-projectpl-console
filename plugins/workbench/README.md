# @cyrus/dsh-workbench

在右侧统一管理文件、代码、Diff、浏览器、终端与详情视图。

必需依赖：@cyrus/dsh-personal-shell（installer 一次装齐）。

## Build

```powershell
npx pnpm@11.19.0 run check:plugins
```

## Install

```powershell
dsh plugin --profile web add @cyrus-dsh-workbench-0.1.0-rc.7.tgz
# restart dsh
```
