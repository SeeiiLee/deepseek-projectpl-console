# @cyrus/dsh-personal-shell

Personal Desktop 四轨布局（原生侧栏 | Project Control | Conversation | Workbench）与
布局偏好兼容层（Gate 1）。

## Build

```powershell
npx pnpm@11.19.0 run check:plugins
```

## Install

```powershell
dsh plugin --profile web add @cyrus-dsh-personal-shell-0.1.0-rc.7.tgz
# restart dsh
```
